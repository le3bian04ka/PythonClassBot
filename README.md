# PythonClassBot

Этот бот был написан для того, чтобы попытаться добавить некоторые функции дискорда в телеграмм для более удобного управления чатом класса.\
**Сам код иммет множетство недоработок/багов и подобного, поэтому его использование только на ваш страх и риск!!!**

Команды бота и описание:

## Команды для обычных пользователей
/info - краткое описание бота с основными командами
/prefix - изменение префикса:
  |-<add> - добавить префикс
  |-<edit> - изменить префикс
  \-<remove> - удалить префикс

## Команды для администрации
/op <@username> - сделать пользователя администратором сервера
  \- <edit_perm> - изменение разрешений
    \- <{список разрешений}>
      пример написания:
      {can_post_messages=True,can_edit_messages=True} - пишется **БЕЗ ПРОБЕЛОВ**
/deop <@username> - сделать администратора обычным пользователем
/ban <@username> - забанить пользователя
/unban <@username> - разбанить пользователя
/mute <@username> <time> - замутить пользователя на N времени
/unmute <@username> - размутить пользователя

/event - добавляет метку времени, чтобы бот оповестил чат за n времени до конца таймера
  |- <add> <date> - долбавить мероприятие
  |- <remove> <название метки>
  \- <list> -показывает активные ивенты на сервере
